Cú pháp

Earley chart parser hoạt động ra sao

Parser lưu state theo vị trí token. Ba thao tác Predict, Scan và Complete xây cây mà không gọi thư viện NLP.

Dạng một state

Mỗi state lưu luật, vị trí dấu chấm, nơi constituent bắt đầu và vị trí hiện tại.

[A → α • β, start, end]

Code dùng khóa (lhs, rhs, dot, start, end) để loại state trùng. children giữ nhánh cây đầu tiên theo thứ tự luật.

Điều kiện nhận câu

Parser chỉ nhận khi augmented start state đi từ token 0 đến token n và dấu chấm đứng cuối luật.

[__START__ → S •, 0, n]

Câu còn token thừa không đạt điều kiện này. Hàm ParseResult.output() trả ().

CHART[0]• tuần
CHART[1]tuần • 3
CHART[2]3 • học
CHART[3]học • gì
CHART[4]gì • ?
CHART[5]? •

Pseudocode sát với parser.py

chart[0] ← [START → • S, 0, 0]

for position in 0..n:
  for state in chart[position]:
    if state đã complete:
      advance các state cha
    else if next_symbol là non-terminal:
      predict mọi luật của next_symbol
    else if token[position] khớp next_symbol:
      scan sang chart[position + 1]

accept nếu [START → S •, 0, n] tồn tại

Ngữ nghĩa và tri thức

Cây cú pháp trở thành truy vấn KB

Semantic interpreter đọc nhãn Q_* để lấy intent và đọc constituent có tên để lấy entity. Nó chưa mở KB ở bước này.

CÂYQ_SCHEDULE_WEEK
└─ WEEK_ENTITY: tuần 3
→
PREDICATEGET_SCHEDULE(
week=WEEK_03)
→
LOOKUPKB.weeks[WEEK_03]
source: schedule.txt

Intent

Nhãn Q_SCHEDULE_WEEK ánh xạ sang GET_SCHEDULE. Bảng BRANCH_INTENTS giữ ánh xạ này.

Entity

WEEK_ENTITY chứa “tuần 3”. EntityLexicon chuẩn hóa thành khóa WEEK_03.

Slots

Frame giữ {week: WEEK_03}. Query engine chọn đúng index mà không quét FAQ.

Cập nhật lúc nào

Context chỉ ghi entity khi query tìm thấy dữ liệu. Một câu lỗi không xóa hoặc thay entity đang nhớ.

Generation và evaluation

Grammar tự kiểm tra bằng chiều ngược

Generator sinh từ CFG. Parser đọc lại từng câu. Evaluation chấm intent, entity, query-status và fact trong answer.

1 · CHỌN NHÁNH

Phân bổ quota cho từng non-terminal Q_*.

2 · KHAI TRIỂN

BFS thay non-terminal ngoài cùng bên trái bằng một RHS.

3 · PHANH

Giới hạn 10.000 câu, số token và số sentential form.

4 · ROUND-TRIP

Parse lại. Lệnh all dừng nếu có một câu bị từ chối.
